# 📚 Subh-e-Dastaan

### Every Dawn Brings a New Story ✨

**Subh-e-Dastaan** is an elegant online novel bookstore designed for readers who love exploring beautiful stories. It brings Urdu and English novels together in one place, offering a delightful browsing experience for book lovers.

## 🌸 About the Project

Inspired by the beauty of literature and storytelling, Subh-e-Dastaan aims to create a welcoming online space where readers can discover their favourite novels, explore new authors, and find their next great read.

📍 **Location:** Khanpur, Sindh, Pakistan

## 🚀 Getting Started

To run the project locally:

1. Clone or download this repository.

2. Open the project folder in your code editor.

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

*These commands apply if the generated project uses Vite and npm.*
